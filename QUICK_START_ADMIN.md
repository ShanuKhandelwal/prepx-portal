## 🐛 Troubleshooting

### "No Users" message?
```
→ Go create a user account first
→ Go back to /admin
→ User will appear
```

### Download button disabled?
```
→ Create at least one user account
→ Refresh the page
→ Button will be enabled
```

### Can't open CSV?
```
→ Right-click file → Open With → Excel
OR
→ Open Excel → File → Open → Select CSV
OR
→ Use Google Sheets (upload file)
```
