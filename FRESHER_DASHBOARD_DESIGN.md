```

│      Learn to craft a winning resume   │
│                          Click to expand →
└────────────────────────────────────────┘
```

**Expanded State:**
```
┌────────────────────────────────────────┐
│ [📝] Resume Building Guide             │
│      Learn to craft a winning resume   │
│                                        │

│                                        │
│ What you'll learn:                    │
```

### Hover Effects
- Cards lift up (2-4px)
- Shadow increases
- Slight scale transform
- Text color changes on links

### Button Effects
- Background color transitions
- Lift animation on hover
- Cursor changes to pointer
- Box shadow deepens

## ✨ Animation Effects

```
1. Page Load:
   - Fade in hero section
   - Cards appear with stagger effect
   
2. Card Expand:
   - Smooth slide down animation (300ms)
   - Opacity increase
   
3. Hover Effects:
   - Cards: translateY(-8px)
   - Buttons: translateY(-2px)
   - Shadows increase
   
4. Timeline:
   - Line animates from left to right
   - Markers appear with scale effect
```

## 📊 Section Heights & Spacing

```
Hero Section:       60px padding top/bottom
Features Section:   40px margin bottom
Timeline Section:   40px padding top/bottom, 50px height
Paths Section:      40px margin bottom
Tips Section:       40px margin bottom
CTA Section:        50px padding
Container:          40px left/right, 20px top/bottom (mobile)

```

## 🔤 Typography

```
H1 (Hero Title):
  - Size: 3rem (desktop), 2rem (tablet), 1.5rem (mobile)
  - Weight: 900 (Extra Bold)
  - Color: White
  - Shadow: 2px 2px 4px rgba(0,0,0,0.2)

H2 (Section Titles):
  - Size: 2rem
  - Weight: 800 (Bold)
  - Color: White (gradient sections), #0f172a (white sections)

H3 (Card Titles):
  - Size: 1.2rem - 1.3rem
  - Weight: 700
  - Color: #0f172a

H4 (Sub Titles):
  - Size: 1rem - 1.05rem
  - Weight: 600-700

Body Text:
  - Size: 0.9rem - 1rem
  - Weight: 400
  - Color: #475569 (gray)
  - Line Height: 1.6

Buttons:
  - Size: 1rem - 1.05rem
  - Weight: 700 (Bold)
```
